# Bundled code font

JetBrains Mono NL Light, version 2.304, unmodified. The NL face keeps source operators as separate glyphs. This static Light face has OpenType weight 300; egui's dark-mode text rendering makes the Regular face look noticeably heavier than in native editors. No font installation is required.

Source: [JetBrains Mono v2.304](https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304), `fonts/ttf/JetBrainsMonoNL-Light.ttf`.

The optional Consolas and Cascadia Mono faces are read from the user's Windows Fonts directory and are not redistributed. If unavailable, code uses the bundled face. UI fonts retain their independent proportional family and fallbacks.
