# Bundled Dart syntax

The Dart grammar comes from the Dart project's primary TextMate grammar:

- Repository: https://github.com/dart-lang/dart-syntax-highlight
- Pinned revision: `122ddbf14fa40d617a8d547140bf8f3114212273`
- Source: `grammars/dart.json`, grammar version 1.8.0
- License: BSD 3-Clause; the complete notice is in `DART-LICENSE.txt`.

`dart.upstream.json` is the unmodified upstream source. `Dart.sublime-syntax`
is generated by `python scripts/update-dart-syntax.py` using Python's standard
library. The editor embeds the generated grammar, so syntax coloring works
without installing a Dart SDK or a language server.

The conversion preserves repository includes, ordered patterns, begin/end
contexts, capture scopes, dynamic end backreferences, nested block comments,
raw and multiline strings, and string interpolation. Sublime capture mappings
cannot recursively tokenize a capture: the upstream function-call generic-type
capture is therefore assigned `meta.generic.dart`; standalone type-argument
contexts keep their individual token scopes. Updating the source requires
regenerating the converted file and running the Dart syntax tests.

The bundled grammar is initialized on the existing background syntax worker.
It adds to the default syntax set rather than replacing other languages.
